============================================
images/  目录约定
============================================

本目录存放「工艺详情页」用到的所有图片。
每条工艺的图片建议放在以「工艺厂 / 工艺id」命名的子目录里，便于管理：

    images/
    ├── Dongbu/
    │   └── Dongbu151abd13sa/
    │       ├── 1.png
    │       └── 2.png
    ├── CSMC/
    │   └── C1813_0.18um_CMOS_EN/
    │       └── layout.png
    └── ...

--------------------------------------------------
图片在 data.json 里的引用方式（只存路径，不存 base64）
--------------------------------------------------
{
  "Dongbu": [
    {
      "id": "Dongbu151abd13sa",
      "version": "1.0",
      "updateDate": "2026-09-05",
      "detail": {
        "text": "本次更新内容...",
        "images": [
          "images/Dongbu/Dongbu151abd13sa/1.png",
          "images/Dongbu/Dongbu151abd13sa/2.png"
        ]
      }
    }
  ]
}

注意：images 数组里的每一项都是「相对路径字符串」，相对于 index.html 所在的根目录。
上传图片 + data.json 后，Netlify 会自动重新部署。

--------------------------------------------------
推荐尺寸 / 体积
--------------------------------------------------
- 单张建议 < 500KB（可先用工具压缩，如 TinyPNG）
- 格式：jpg / png / gif / webp
- 命名用英文 / 数字，避免中文与空格（防止路径编码问题）
